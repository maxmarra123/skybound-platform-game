# Skybound: Brutus' Stadium Run

Skybound is a four-level browser platform game set in Ohio Stadium. Players control Brutus Buckeye, collect block-O collectibles, avoid Michigan football-player enemies and hazards, and defeat a large Michigan M boss.

## Play and source

- Public game: https://maxmarra123.github.io/skybound-platform-game/
- Repository: https://github.com/maxmarra123/skybound-platform-game

## Controls

- Left/Right arrows or A/D: move
- Space, W, or Up arrow: jump
- Esc: return to level select

## Play loop

The game displays the current level, lives, collectible progress, timer, and final-boss health. Losing all three lives restarts the run at Level 1. Collect every block O, reach the goal, defeat the final boss, and finish all four levels to see the total-time championship screen and restart option.
