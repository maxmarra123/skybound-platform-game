# Unfamiliar-User Test and Revision

An unfamiliar user (my roommate) played the game and said it needed a clearer title screen, more difficulty progression between levels, more game feedback such as sound effects, and stronger visual polish. I used that feedback to add a title screen, make later levels progressively more difficult, add sound effects, and improve the visuals. I also tried power-ups after the test, but removed them from the final version because they did not improve the game. The roommate played the revised version again and enjoyed it more.
